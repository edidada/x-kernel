# X-kernel website

A readable React + Vite website for X-kernel. The site presents the project, its component boundaries, documentation, and bilingual blog content.

## Run

```sh
npm install
npm run dev
npm run build
npm run preview -- --host 0.0.0.0
```

The development server listens on port 56111. Fonts and image assets are local.

## Read the source

Start at `src/main.tsx`, then `src/pages/home/HomePage.tsx`:

- `Navbar` in `HomePage.tsx`: responsive navigation and dropdown state.
- `Testimonials` in `HomePage.tsx`: testimonial carousel.
- `TerminalPlayer.tsx`: terminal recordings and playback controls.
- `src/shared/styles/home.css`: original public homepage layout and responsive rules.
- `markdown/`: bilingual documentation and blog source, JSON indexes, and SVG assets.

The source is reconstructed, not the original author's source code. Production Vite builds still minify dependencies under `dist/`; that is normal. Read and edit `src/`, not `dist/`.

## Backend boundaries

This repository is a static X-kernel website. It does not provision machines or provide a kernel control plane; operational commands and source links point to the X-kernel repository.

Documentation and blog content are authored in English and Simplified Chinese.

The website is implemented with React and Vite. The kernel content is generated from Markdown at build time; the application does not load the original site runtime.

Visual assets and copy in this repository belong to their respective authors; this is the X-kernel project website.

## Asset and style directories

- `assets/fonts/`: locally vendored JetBrains Mono (400/600/700), CSS declarations and original OFL license. All existing language subsets and WOFF/WOFF2 fallbacks are preserved.
- `assets/images/`: images imported by React; Vite manages their production URLs.
- `src/shared/styles/`: global, theme and component styles.
- `public/`: browser icons that require stable public URLs.

The font package is no longer needed at runtime or install time.

`dist/` is generated by `npm run build` and ignored by Git. It can be deleted safely; the development server uses source files and does not need it. Build again before running `npm run preview` or deploying.

See `markdown/README.md` for content authoring and `package.json` for validation commands.

Theme selection uses `next-themes`; `ThemeToggle` is a thin icon button over its `useTheme` API.

The application is organized by product boundary. See `src/app`, `src/pages`, `src/features`, `src/entities`, `src/shared`, and `src/mocks`; page components consume repository contracts rather than importing fixture arrays directly.
