# irq-types — 安全与可靠性

## 范围与边界

全部代码为无依赖的 Copy 值类型、派生比较和整数包装/读取，没有 unsafe、
指针、分配、I/O、锁、回调、全局状态或宿主调用。

输入来自宿主或固件解码者。Unknown(u32) 原样保存未知触发标志，
不代表这些标志可直接用于配置硬件。IrqController 不标识具体实例。

## 风险与责任

- 任意 IrqDomainId 都可构造：它不是已注册域的证明或访问凭证，
  宿主 IRQ 核心必须验证域存在并拥有正确路由。
- 域编号跨宿主或不同命名空间比较没有身份保证，转换者必须保证来源一致。
- 本 crate 不保证域编号不会复用、不保活域，也不授权 IRQ 注册或释放。
- 共享类型不会把设备 IRQ 回调变成内核或 pseudo-NMI 回调；
  回调协议与转换由上层契约及宿主适配负责。

本轮只移动既有值定义，保留全部枚举变体、比较行为和域编号表示。
