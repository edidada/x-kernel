# 驱动设备模型术语

- **设备**：总线枚举发现的对象；是否存在不取决于有没有驱动管理它。
- **设备注册**：将设备纳入框架管理，建立其身份与注册关系。
- **驱动绑定**：某个驱动管理某个已注册设备的一段关系；同一设备可以先后经历多次绑定。
- **驱动解绑**：结束当前绑定及其运行职责，不等于注销设备本身。
- **设备注销**：结束设备的注册关系；若仍有绑定，需要先结束该绑定。
- **设备引用**：保留某个设备对象的身份与描述，不代表设备仍可操作。
- **注册权**：承担结束设备注册关系的权限与责任，不等于保有设备身份引用。
- **拓扑父设备**：描述设备所处的父子关系，不单独决定谁负责注销它。
- **下游注册归属**：说明某项注册由主机集成层或某次控制器绑定负责；不取决于设备描述来自固件还是动态探测。
- **能力发布**：向消费者提供运行能力；其可用期不等同于来源设备元数据的存活期。
- **发布注册权**：承担撤销一项能力发布的权限与责任，不等同于设备注册权或消费者句柄。
- **操作许可**：允许一次操作使用尚未撤销的能力，并要求退出流程在操作结束前保护其所需资源。
