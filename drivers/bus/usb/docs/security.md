# `bus/usb` 安全说明

本文件记录这一层的信任边界、外部输入与失败处理。它与 `docs/design.md` 配套阅读。

## 1. 信任边界

| 输入 | 来源 | 信任级别 |
| --- | --- | --- |
| 设备描述符（device/config/interface/endpoint/SS companion/hub） | **设备自身**，经控制传输读入 | 不可信 |
| 字符串描述符（厂商/产品/序列号） | 设备 | 不可信，仅用于日志 |
| BOT 响应（CSW status/residue、READ CAPACITY、扇区数据） | 设备 | 不可信 |
| hub 上报的端口状态/变化位 | 设备 | 不可信 |
| `SetupPacket`、`BotEndpoints`、`UsbDevice` | 内核内部（枚举结果） | 已校验 |

控制器寄存器与 DMA 不在此层（`drv/usb`），本层只通过 `Hcd` 契约请求传输。

## 2. 不可信输入如何被约束

1. **长度先校验后使用**：控制传输的 `length` 取 `min(buffer.len(), wLength)`；
   BOT 数据阶段按扇区数计算，`read_sectors` 拒绝超过上限的请求。
2. **描述符解析逐项设上限**：配置描述符总长、接口数、端点数字段均按描述符长度
   迭代，越界即停止解析而不是继续读；`bMaxPacketSize0` 只接受 8/16/32/64/512 等
   合法值（在枚举层判断），不合法即放弃该设备。
3. **不按设备字符串做控制流决策**：厂商/产品串只出现在日志里（历史教训：曾按产品名
   `x5000m` 误判设备类型；正确依据是 interface class 与容量）。
4. **容量来自设备但只用作上限**：`READ CAPACITY` 的 LBA 只用于设定块设备的
   `num_blocks`；实际读写仍由调用方给出 `block_id`，越界由块层与本层的
   `block_id + done` 计算共同约束（`sectors` 上限 8）。
5. **hub 端口号/端口数**：`bNbrPorts` 用于迭代，`port_status()` 对越界端口返回错误；
   端口复位等请求只对已上报端口发出。
6. **状态机拒绝非法转换**：`UsbBus::attach()` 拒绝同地址重复注册；
   `UsbBus::bind()` 拒绝同一接口重复绑定；两者的失败都不留下条目。

## 3. 设备表的所有权与锁序（本特性引入）

- 表内保存 `ClassBinding`，其 `owners` 是**类型擦除的撤销所有者**
  （`Box<dyn Any + Send + Sync>`）。drop 即撤销；表本身**从不**在持控制器锁时 drop
  它们（`detach()` 返回所有者，调用方在锁外释放）。
- 锁序固定为 **`UsbBus` 锁 < 控制器锁**。违反它会在设备移除时自锁
  （`Publication → 块后端 → Arc<Mutex<Hcd>>`）。
- 控制器实例持有 `Arc<Mutex<UsbBus>>`，而发布物又间接持有控制器：这是**引用环**，
  在本框架里意味着驱动卸载时表不会被释放。当前接受（驱动生命周期等于系统生命周期），
  如果要支持卸载，需要把表的所有权上移到组合根并显式 `detach_all()`。

## 4. 失败处理

| 失败 | 行为 |
| --- | --- |
| 描述符读取/解析失败 | 该设备不被注册；端口保持连接，下一轮扫描可重试 |
| 容量读取失败 | 不发布块设备（不产生半绑定） |
| 类发布失败 | `bind()` 之前即返回错误，局部 `Publication` 就地 drop 撤销 |
| 设备消失（`CCS == 0`） | 下一轮 `rescan`/`detach_absent` 摘除其绑定 → `/dev` 节点消失，读写立刻失败而**不是挂死** |
| 控制器错误事件（`hc_error`） | 摘除全部绑定并复位控制器；设备在下一轮扫描重新枚举 |
| 传输超时 | 端点修复（Reset Endpoint + Set TR Dequeue）一次；仍失败则返回错误，不做无限重试 |

## 5. 已知未覆盖（不在本层）

- 无中断路径：端口变化靠轮询，最坏延迟为一个扫描周期。
- 未实现 runtime PM / USB3 LPM，因此不存在"设备被自动挂起后失效"的路径。
- 未实现 isochronous 与 streams：相应描述符会被解析但不会被绑定。
- 设备表当前只在驱动生命周期内存在；驱动卸载语义未定义（见 §3）。
